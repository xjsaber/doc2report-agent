# 第 3 轮任务 3：独立 RAG 知识库问答页

日期：2026-10-27；基线：9578acb [retrieval]。仅完成任务 3，不改检索契约。

## 要解决什么

按 ROADMAP v1 增加可单独启动的 Streamlit 问答页：上传/选择 PDF → 解析入库 → 混合检索 → 调模型回答；回答必须带 `[文件名 p页码]`，无依据时拒答；无 API Key 时只展示检索结果。

## 决定

- 业务逻辑放在 `core/qa/`（`answer_question` + OpenAI 兼容客户端），`app/rag.py` 只做 Streamlit UI，不依赖报告 LangGraph。
- Key 只从环境变量读取；页面启动时用极简 `load_dotenv_config` 加载根目录 `.env`（不覆盖已有环境变量）。不把 `.env` 入库。
- 默认 `MODEL=deepseek-flash`；未配置 `API_KEY` 时 `build_chat_model()` 返回 None，页面/服务进入 retrieval-only。
- 检索无命中时明确拒答；模型漏写引用时，用已命中片段的真实 file/page 追加「参考：」标记，不编造页码。
- streamlit/openai 放 optional extra `qa`；pytest 用 `FakeChatModel`，不下载模型、不联网。
- Windows 默认仍走 memory Retriever + 测试假 embedding。

## 环境、坑与测试

运行环境预期：原生 Windows，仓库 `.venv` Python 3.12；本机有 RTX 3050，本任务问答链路测试不用 GPU。笔记本一度离线，实现先在同步环境完成后再回灌本机提交。

安装：`pip install -e ".[dev,qa]"`。启动见 README「单独启动问答页」。
