# 第 5 轮 · 任务 3 [e2e]

## 这一步要解决什么
用真实 bge-small-zh-v1.5（CUDA）与真实模型对公开年报跑完整 CLI；问答页抽测；截图；README 作品化；记录观察（不编效果数字）。

## 我做了哪些决定
1. Embedding：本地缓存优先（`local_files_only=True`），缺失时允许一次性网络拉取；模型文件仍不入库。
2. 切块：`merge_short_chunks` 合并同章节过短相邻块（阈值 `min_chars/2`），实跑后由约 17.5 块/页降到约 11.17 块/页（185 页 → 2066 块）。
3. 实跑走 CLI + 独立 QA 链路，观察写入 `docs/devlog/`；不提交 PDF、`.env`、`output/`、模型权重。
4. README 改作品页：一句话介绍、截图表、Mermaid 架构、安装/启动（Windows cmd + Linux/WSL）、配置表、测试结果、已知限制、v2。
5. 截图优先 Playwright 无头；Word 窗口若无法稳定无头截取则在回报中列为缺图。

## 踩了什么坑
- 本机 git https 连 GitHub 偶发 Connection reset；push 需重试或 HTTP/1.1。
- pytest 默认 Temp 目录权限异常，继续 `--basetemp=.tmp/pytest/basetemp`。
- verify 数字校验偏严：五章均有引用且 `rewrite_count=1`，但核验仍为 `mismatch`/`pending`（数字未能在被引片段原文精确匹配）。
- 观察 JSON 部分中文字段在管道写入时出现编码乱码，devlog 以人工核对后的摘要为准，不依赖乱码字段。
