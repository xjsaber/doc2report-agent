# doc2report-agent

文档 → 报告智能体：上传上市公司公开年报 PDF，按可配置模板生成带出处（文件名 + 页码）的《企业经营分析报告》初稿，并导出 Word。

> 状态：v1 开发中。开发约定见 [AGENTS.md](AGENTS.md)，需求见 [docs/CODEX_PROMPT.md](docs/CODEX_PROMPT.md)，工具规范见 [docs/TOOLS_SPEC.md](docs/TOOLS_SPEC.md)，分期见 [docs/ROADMAP.md](docs/ROADMAP.md)。

本项目只使用公开数据和原创代码、提示词，与任何机构的内部系统无关。
